# Archived historical outputs

These files preserve the original single-seed record. They are not the source
of current headline claims.

The step-500 checkpoint and 200-node test dataset survive and reproduce the
recorded test accuracies. The original validation dataset and dirty training
diff do not survive, so the validation table, validation sweep, historical
losses, and historical convergence curve cannot be independently regenerated.
They remain here as provenance records, not verified results.
